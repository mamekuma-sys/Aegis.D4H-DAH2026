## 실행 이미지 확인

- R3·R4 공격 로그는 모두 `0.3.0-p1ports`, `sol-fallback+p1-grpc`를 기록했다.
- R3·R4 방어 로그는 모두 `defender-2026-08-21-p1r1-8080-hotfix`, ACTIVE 9개를 기록했다.
- 따라서 `4f3b016`과 그 직전 P2 보강은 두 라운드 실전 컨테이너에 배포되지 않았다.
- R3 공격자는 SatDiag Tail 경로로 5개 flag 제출을 accepted 받았고, R4 로그에는 같은
  경로의 hit 3개가 있다. R4 공격 로그에는 종료 summary가 없어 accepted 총계로 확대 해석하지 않는다.

## 현재 후보 재생 결과

`defender-2026-08-21-p2r4-evidence-fix`를 P2 R3·R4 PCAP 10개에 재생했다.

- ingress TCP packet 196,937개와 완성된 HTTP request 21,324개를 처리했다.
- 독립 라벨의 HTTP exploit shape 2,355/2,355를 차단했다.
- 기타 HTTP request 18,969개는 모두 통과했고 예상 밖 DROP은 0개였다.
- HTTP flag-linked request 16/16을 차단했다.
- 9000에서는 SatDiag Tail 43 packet, Export 44 packet이 ACTIVE 규칙에 일치해 차단됐다.
- `GET /portal/feedback?service_id=...` 2건만 공격 형태로 차단했고, query 없는
  `/portal/feedback` 10건은 정상 negative로 통과시켰다.

이 수치는 offline PCAP proxy이며 공식 SLA 오탐률이나 실제 Docker 배포 성공을 뜻하지 않는다.
