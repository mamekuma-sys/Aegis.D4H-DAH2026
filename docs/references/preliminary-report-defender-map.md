# 예선 보고서 페이지별 방어 설계 매핑

본선 방어 런타임 설계(`docs/superpowers/specs/2026-08-11-defender-runtime-design.md`)가 예선 보고서 전체를 근거로 검토했음을 추적하는 문서다. 물리 PDF 페이지 1~54를 각각 한 행으로 기록한다.

**본선 supersession:** 예선의 circuit-breaker·자동 복구 아이디어는 역사적 입력으로만 보존한다. organizer-guaranteed 정상-health/SLA 신호가 없는 본선 `raw_ip` 계약에서는 packet-derived `raw_drop_rate`, `baseline_violation_rate`, `rule_concentration` 등이 runtime policy를 자동 전환할 수 없다고 최종 판정했다. 이 값은 metric·경보·Break 사람 검토에만 쓰며, rollback·승격은 승인된 다음 이미지의 PolicyBundle에서만 발생한다. 최종 구현 권한은 방어 설계 §10.3과 `research/defense-mapping.md`에 있다.

## 핵심 결론

예선 보고서의 방어 체계는 **MAVLink 명령·파라미터·텔레메트리 의미론**을 입력으로 삼는다. 본선 방어 에이전트의 계약된 입력은 Broker가 전달하는 인바운드 `raw_ip` 패킷뿐이므로(운영세칙 제13조 1항, `contracts/defender/README.md`), 의미론 계층에 의존하는 방어 방법 3선은 관측 근거를 확보할 수 없어 제외한다.

| 예선 방어 5선 | 필요한 입력 | 본선 판정 |
|---|---|---|
| Mission Context Validator (S1) | Mission Plan, Vehicle State, Mission Phase | **제외** — 세 맥락 모두 미관측 |
| Golden Profile + 해시 체인 (S2) | 파라미터 전체 세트, `PARAM_SET` 메시지 | **제외** — 파라미터 저장소 미관측 |
| Physics-Based Detector (S3) | 명령·센서·역학 파라미터(질량, 추력 계수, 항력 계수) | **제외** — 기체 상태 미관측 |
| Causal Graph 상관분석 (S4) | 이벤트 간 세션·시간·인과 키 | **재설계** — verdict 이후 비동기 경로로 이동 |
| Deterministic-AI 이중판단 (S5) | 독립 입력 파이프라인 2개 | **계승** — 300ms 시간 계약이 이 구조를 강제 |

살아남는 것은 **구조적 원칙**이다. 다계층 누적 상관, 결정론적 판단과 AI 판단의 분리, 가용성 우선 대응 셋은 입력 도메인이 바뀌어도 유효하며 본선 설계의 축이 된다.
