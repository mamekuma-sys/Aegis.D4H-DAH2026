# 예선 보고서 공격 설계 페이지 매핑

이 문서는 예선 보고서 원본 PDF 전체(물리 페이지 1~54)를 페이지별로 검토했다는 추적 근거다.
각 물리 PDF 페이지를 한 행으로 기록하고, 본선 공격 설계 관점에서 `계승`·`재설계`·`배경`·`제외`
중 하나로 판정한다. 원문을 그대로 복사하지 않고 팀의 표현으로 요약한다.

## 원본 동일성

| 항목 | 값 |
|---|---|
| 원본 ID | `PRELIM-REPORT` |
| 파일명 | `DAH2026_예선보고서_Aegis.0xD4H.pdf` |
| 예상 SHA-256 | `1DD42B99A8816C3B7A543929BA0AEE90E5565CFC853E19E1455F76631CD1894E` |
| 확인한 SHA-256 | `1DD42B99A8816C3B7A543929BA0AEE90E5565CFC853E19E1455F76631CD1894E` (일치) |
| 확인한 물리 페이지 수 | 54 |
| 검토 방식 | 페이지별 텍스트 정독 + 그림·도식 포함 페이지 이미지 렌더 시각 확인 |

원본 PDF는 저장소 밖 비공개 팀 보관소에서 읽었으며, 추출 텍스트·렌더 이미지·임시 PDF를 저장소에
추가하지 않았다. 인벤토리(`docs/references/source-inventory.md`)의 `PRELIM-REPORT` 행과 해시가 일치한다.

## 판정 기준

- `계승`: 본선 공격 설계에도 같은 원칙을 직접 사용
- `재설계`: 목적·아이디어는 유지하되 본선 입력·출력·시간·네트워크 계약(HTTP 서비스 관측·`TARGETS×PORTS`·flag 제출)에 맞게 구조를 변경
- `배경`: 위협 모델·상대 방어 이해·실험 맥락처럼 설계 판단의 배경으로만 사용
- `제외`: 합성 데이터 전용, 본선 인터페이스에서 관측 불가, 실행 권한 없음, 공격과 무관 등

주의: 예선 세그먼트(필드·통신·지상·클라우드·거버넌스)와 본선 레이어(위성망 게이트웨이·MCS·UAV·UGV)는
이름이 유사해도 동일시하지 않는다. 예선 보고서는 UAV/UGV·MAVLink 도메인의 **합성(simulation) 위협 모델**이고,
본선 표적은 공식 스켈레톤 기준 **포트로 노출된 HTTP 서비스**다(스켈레톤 `agent-guide.md`, 데모 챌린지 관측).
예선의 취약점 존재는 본선 사실이 아니며, 본선 운영세칙 제11조 ③에 따라 취약점과 flag는 1:1 대응하지 않는다.

`FinalsPhase·레이어` 열의 대응은 도메인 근접성에 따른 **참고 힌트**이며 취약점 목록이 아니다. 활성화는 실제 관측 증거를 요구한다.

## 검토 관점 커버리지 (§6.3)

보고서의 실제 목차에 따라 다음 관점을 모두 확인했다.

- 문제 정의·시스템/자산 범위: 1.4·1.5 (p3~4)
- 공격자 모델 A1~A5: 1.6 (p5) — 재설계
- 공격 시나리오 S1~S5 단계·선행조건·성공조건: 2.3~2.7 (p8~11) — 재설계
- 다단계 시간·세션·대상·인과 연결: 2.6 S4·3.3.4 (p10, p26~29) — S4는 재설계, 방어 상관은 배경
- 이벤트 스키마·정규화: 4.5 (p43~44) — 배경(방어 스키마), 데이터 구성은 제외
- 결정론 규칙·AI 조언·결과 비교: 3.3.5·4.2.2·4.4 (p30~32, p40~42) — 배경
- 상관분석·시간창·인과 그래프·위험도: 3.2·3.3.4 (p15, p27~29) — 배경
- 대응·가용성·rollback·HITL: 3.5~3.7 (p33~37) — 배경(가용성=SLA 연결)
- 데이터 생성·평가·지표·결과: 4.6~4.9 (p44~46) — 제외(합성 수치)
- 예선 구현 구조·기술: 4.8 (p45) — 제외
- 한계·가정·결론·향후: 5.1~5.3 (p47~49) — 한계·정직성은 계승, 확장은 배경
